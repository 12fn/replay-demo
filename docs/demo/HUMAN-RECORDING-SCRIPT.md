# REPLAY — human recording script

**Target:** about three minutes. **Audience:** an instructor reviewing a fictional training decision, with a program or technical reviewer watching. **UI baseline:** native 0.28.3. This is a recording guide, not a claim that a new video or human acceptance test has been completed.

Open the REPLAY URL supplied by your deployment operator and use native Kamiwaza sign-in. This guide describes a prepared instructor recording; a fresh source checkout does not include another user's private qualification records.

## Before recording

1. Sign in normally with your authorized account; keep the sign-in and credentials outside the recording. Use a readable full app window at 1440×900 or larger, with browser zoom at 100%.
2. Open **Instructor case → Return to original case**. Confirm **Recorded native workflow** is visible. If it instead says **Authored synthetic rehearsal**, stop and select the intended native case; do not describe the two records as the same run.
3. Confirm the exercise has ended and the model opponent is off. Note the current counter in **Platform → Usage & records**, then return to **Instructor case**. This route uses a free evidence calculation and already saved analysis; do not generate a new debrief or enable a model.
4. Rehearse the source lookup below once. If that named source is absent, select an actual available source and revise the spoken wording before recording. Keep the complete Kamiwaza and Computacenter marks visible where the responsive shell places them.

## Three-minute core

Read **Speech** aloud. Follow **Screen** silently. Pause after each click so the result can be read. Keep the full app in frame; use a steady cursor rather than repeated zooms.

| Time | Screen — do not read aloud | Speech |
|---|---|---|
| 0:00–0:20 | **Instructor case → The decision**. Hold on the case title, provenance badge and original-record notice. | “REPLAY helps an instructor review a decision using the evidence available at the time. This is a fictional training case with a recorded native workflow. We’ll inspect its sources, question the saved AI interpretation, and open the evidence handoff.” |
| 0:20–0:50 | **The evidence → Retrieve this decision’s evidence**. Wait for the graph and its actual returned counts. | “This button runs a free calculation over this decision’s recorded relationships. The highlighted path shows what was traversed. The graph is useful because it takes us back to the source behind the decision.” |
| 0:50–1:20 | In **Find entity**, enter `Bulletin: reed-flat reserves`. Select the matching graph node, or use **Browse graph nodes as a list**. Hold on its excerpt and availability. Open **What would change the judgment** if visible. | “Here is the source excerpt and its timing. A repeated report is not automatically independent corroboration, and availability does not prove someone read it. The assumptions and missing evidence remain open for the instructor to challenge.” |
| 1:20–1:55 | **AI assistance → Read the saved model analysis and cited evidence**. Open one **Inspect headline source** button, hold on **Exact saved citation**, then **Close saved citation**. | “This is a saved AI analysis. Opening it makes no new model request. I can inspect a cited passage and compare it with the interpretation. A citation link alone does not establish that the interpretation is correct.” |
| 1:55–2:20 | Open **Recorded native receipts and correction**. Show the saved correction and receipt; do not create a new review or request. | “The original analysis and its separate correction are retained. These recorded correction actions demonstrated the software; they are not evidence of human instructor acceptance or improved learning.” |
| 2:20–2:50 | **Next practice → Download complete evidence packet**. Open the actual downloaded JSON in a readable viewer. Show the exercise identity and one source or review entry that is genuinely present. Do not click **Start a new legal practice branch** in this short cut. | “The handoff is an actual evidence packet that another reviewer can reopen. It preserves the record behind the discussion. An instructor can use this review to plan the next practice; measuring learning improvement requires a separate evaluation.” |
| 2:50–3:00 | Return to the app. Hold the case and both shell brands long enough to read. | “The result is a reviewable decision, inspectable evidence, and a durable handoff.” |

If a download is blocked or a source fails to open, stop and fix the rehearsal. Do not narrate a successful result over an error. Read values only from the current screen; the script intentionally promises no fixed node count, confidence score or benefit figure.

## Accuracy and recording notes

- Use “Kamiwaza deployed model” only for a model deployed through the platform. For the qualified external API route, use the UI label “Connected model.” Native app sign-in does not establish local GPU inference. Exact identities remain in technical receipts and exports.
- Recorded analysis stays recorded. The free graph calculation is deterministic, not a new model inference. This cut creates no new exercise, gameplay order, paid request or instructor note.
- Keep government endorsement, operational effectiveness, certified compliance and validated learning claims out of the narration; none is established by this recording.
- After the take, confirm the request counter is unchanged, inspect the actual export and listen to the entire recording once. Keep a mistaken take separate from an accepted cut.
- The supplied logos belong to the shell. Do not insert them into record contents or imply that they appeared in older retained footage. A separate editorial closing card may hold both marks for two seconds without an inference claim.
