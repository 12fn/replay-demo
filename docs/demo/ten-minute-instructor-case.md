Each practice branch is independent and remains visible. Saved notes remain append-only; a correction file uses a new note ID plus `revisionOf`. Re-importing identical bytes returns the original receipt without duplicate notes.

If a native cached debrief says evidence changed after this upgrade, show its saved result and historical receipt. If the managed archive is unavailable, state that source readback is unavailable and show the locally verified decision source and portable recorded analysis. Do not claim native archive success from a local fallback.
