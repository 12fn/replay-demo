# Public REPLAY source maintenance

Read README.md and PUBLIC-RELEASE.md before editing. REPLAY is a training and assistance layer for wargaming; the current game is a reference environment. Keep planned game import and physical reconstruction distinct from shipped capabilities.

Preserve deterministic replay, legal-action validation, branch isolation, native authorization, perspective-scoped retrieval, citations and durable records. Verify relevant tests and the actual browser workflow after application changes. Do not replace native identity with a public persona switch.

Never commit credentials, private deployment configuration, recordings, databases, browser/session state, raw model-provider traces or personal agent history. Use public or synthetic test inputs and keep inference disabled in ordinary tests. Preserve source obligations and third-party notices.

Keep new work and verification in the project folder. Maintain an explicit publication allowlist; inspect the Git diff and generated source archive before publishing. Do not copy private development history into this public repository.
