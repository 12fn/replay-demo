## Architectural choices

- Reuse native identity/workrooms, catalog byte storage, model route and Tomo tools. Preserve the REPLAY engine, canonical ordered events, branch isolation, observation signatures and budget ledger.
- Source/time/side authorization precedes deterministic retrieval; native unsourced facts cannot act as evidence. Graph construction is bounded on a requested review, never an external dependency on the game clock.
- Save original notes in the existing exercise database first. Do not invent native catalog/parser success while source arrays and parsing dependencies are unwired.
- Retain the existing61exercise snapshot/ninearchivedtrials as recorded evidence. Prepared fictional history stays unattributed; new participant branch actions remain attributable and marked informed practice.
- Broader federal use still needs approved content, real instructor/participant acceptance, security and restore qualification, measured concurrency and the target hardware. No claim of completed operational qualification follows from these tests.
